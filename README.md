# فاتورا · Fatoura

فواتير وعروض أثمنة للمستقلين والمقاولين الذاتيين في المغرب — عربية أولًا، بدون حساب، وبياناتك تبقى في متصفحك.

**الموقع:** فاتورة A4 حقيقية، فحص قانوني من 9 نقاط، مبلغ بالحروف، PDF، رابط مشاركة، لوحة متابعة، وأدوات مجانية للسيو.

## التشغيل

```bash
npm install
cp .env.local.example .env.local   # اختياري — للروابط السحابية والبريد
npm run dev                        # http://localhost:3000
npm run build                      # تحقق الإنتاج
```

## الإيرادات

نموذج العمل، الرسائل الجاهزة، وقائمة الإطلاق في **[REVENUE.md](./REVENUE.md)**.
توليد مفاتيح برو: `FATOURA_LICENSE_SECRET=… node scripts/mint-license.mjs you@mail.ma yearly 365 --ref=CASH-001`

## البنية

```
app/            المسارات: / · /new · /invoices · /pro · /tools/* · /i/[token] · /api/*
components/     المستند (invoice-sheet) · المحرّر · اللوحة · صفحة برو · الأدوات
lib/            النماذج، الحسابات، الفحص، التخزين، PDF، المشاركة، الترخيص
scripts/        سكّ المفاتيح + فحوص وقت التطوير
```

- **الحساب** بالدرهم والسنتيم (أعداد صحيحة خلف الكواليس) — لا كسور ضائعة.
- **المستند** مصدر حقيقة واحد (`components/invoice-sheet.tsx`) للمعاينة، الطباعة، PDF، والرابط.
- **الخصوصية** بنية معمارية: لا حساب ولا خادم ولا تتبّع في المسار الأساسي.

## البيئة

| المتغير | الغرض |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | رابط الموقع (metadata/sitemap) |
| `SUPABASE_URL` + `SUPABASE_SERVICE_ROLE_KEY` | روابط المشاركة السحابية + قائمة البريد (اختياري) |
| `GMAIL_CLIENT_ID` / `_SECRET` / `_REFRESH_TOKEN` / `_SENDER` | إرسال البريد مباشرة (اختياري) |

بدون Supabase يعمل كل شيء؛ رابط المشاركة يصبح **ذاتيًا** (الفاتورة مضغوطة داخل الرابط، بلا خادم، بلا انتهاء).
